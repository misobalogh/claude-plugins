# claude-plugins

Claude Code plugins and skills by Michal Balogh.

## Install

```
/plugin marketplace add misobalogh/claude-plugins
/plugin install <plugin>@misobalogh
```

## Plugins

| Plugin | Description |
|--------|-------------|
| [train-recipe](https://github.com/misobalogh/train-recipe) | Stage-by-stage, gate-verified process for training, debugging and improving deep learning and tabular ML models, based on Karpathy's "A Recipe for Training Neural Networks" |
